 Bank Management System

 Project Overview

The Bank Management System is a console-based Java application designed to perform basic banking operations.

This application helps users manage bank accounts, deposit money, withdraw money, check account balances, and display account details.

 Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Display Account Details
- Manage Multiple Accounts

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList (if implemented)
- Scanner Class
- Eclipse IDE

 Concepts Used

- Classes and Objects

- Encapsulation
- Private Variables
- Getters and Setters
- Methods
- ArrayList (if implemented)
- Switch Case

 How to Run

1. Install JDK.
2. Open Eclipse IDE.
3. Create a Java Project.
4. Create a package named `sugunam`.
5. Create the required Java classes.
6. Copy the source code into the respective classes.
7. Run the Main.java file.

 Project Objective

The main objective of this project is to understand Java programming and Object-Oriented Programming concepts by developing a simple banking application.
